## 文脈

運用中のワークフローでは、ビジネススペック（基本設計から詳細設計の一部）を PdO が、実装スペック（詳細設計・API 定義・テーブル設計）を開発チームが書いている。[ADR-008](008-sdd-bridge.md) は spec 一般と KB の受け渡しを定めたが、「実装スペックをそもそも書くべきか、どこまで書くか」には答えていない。

実装スペックには性質の違うものが同居している。[EVID-018](../evidence/018-tests-outlive-design-docs.md) のとおり振る舞いを文書とテストに二重で持つと文書だけが腐り、[EVID-019](../evidence/019-change-cost-is-asymmetric.md) のとおり事前設計が見合うのは不可逆な箇所に限られる。

## 決定

### 1. 実装スペックを単一の成果物として扱わない

3 つに分解し、それぞれ正本を別に置く。

| 中身 | 実体 | 正本 | 文書に書き写すか |
| --- | --- | --- | --- |
| API 定義・テーブル定義・イベントスキーマ | 契約 | 機械可読な定義（OpenAPI / マイグレーション / スキーマファイル） | 書き写さない。図や表が要るなら生成する |
| なぜその契約か、却下した案 | 決定 | ADR | 書く（これだけが文書として生き残る） |
| どう動くのが正しいか | 振る舞い | テスト | 書き写さない |

### 2. 文書としての実装スペックを書く条件

次のいずれかを満たすときだけ書く。満たさないなら書かない。

1. **共有境界がある** — 他チーム・他システム・外部公開が絡み、実装前に合意が要る
2. **不可逆である** — 既存データを持つスキーマ、公開済みの契約など、後から直すコストが桁で高い
3. **選択肢が複数あった** — 却下理由を残す価値がある

単一チームで閉じ、後から変えられる内部実装は対象外とする。そこはテストが仕様である。

### 3. ビジネススペックは受け入れ例まで落とす

PdO が書くビジネススペックには、抽象的な条件だけでなく**具体値と境界値**を入れる。例が TDD の入力になる（[PB-013](../playbook/013-start-tdd-from-examples.md)）。雛形は [templates/acceptance-examples.md](../templates/acceptance-examples.md) を spec リポジトリにコピーして使う。

### 4. 実装スペックの厚みをレビュー観点にする

実装スペックが厚いときは、開発チームの怠慢ではなく**上流の受け入れ条件が曖昧である**サインとして扱う。厚みを減らす手は「実装スペックを削る」ではなく「ビジネススペックに例を足す」である。

### 5. 決定の置き場所

- 他の案件でも同じ判断を繰り返すもの → **KB の ADR**
- その案件限りのもの → **spec / 実装リポジトリ側の ADR**（KB には持ち込まない）

判定は [ADR-008](008-sdd-bridge.md) の境界をそのまま使う。KB 側は spec 本文を持たず、リンクと ID のみを持つ。

## 根拠

- [EVID-018](../evidence/018-tests-outlive-design-docs.md): 振る舞いを二重に持つと文書だけが腐る。例まで落ちた受け入れ条件はテストになる
- [EVID-019](../evidence/019-change-cost-is-asymmetric.md): 事前設計が見合うのは不可逆な箇所に限られる
- [EVID-011](../evidence/011-spec-first-reduces-rework.md): 仕様の空白はエージェントの推測で埋まる。埋めさせないのは上流の具体性である

## 結果・トレードオフ

- 利点: 「詳細設計書を書くか」が好みの問題ではなく、共有境界・不可逆性・選択肢の有無で機械的に決まる
- 利点: 振る舞いの二重管理が消え、テストと契約定義が唯一の正本になる
- 利点: 上流の曖昧さが実装スペックの厚みとして可視化される
- 代償: PdO の負荷が上がる。境界値まで書く作業は、これまで開発チームが解釈で吸収していた分が上流に戻ることを意味する
- 代償: 案件固有 ADR の置き場所と体裁は各リポジトリに委ねられ、KB からは検査できない（[OQ-015](../ledger/open-questions.md)）
- 代償: 「不可逆かどうか」の判定に閾値がなく、当面は人の判断に依存する
