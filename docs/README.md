# docs

Cursor の会話（Cloud Agent の実行ログ）から得られた知見を、1 トピック 1 ファイルの Markdown として残す場所。

## 命名規則

`NN-topic-name.md`（`NN` は 2 桁の連番、`topic-name` は英小文字ケバブケース）。

会話の時系列そのままではなく、扱っているテーマごとにファイルを分ける。1 つの会話から複数ファイルが生まれてよい。

## 各ファイルの構成

`_template.md` をコピーして使う。冒頭に出典（Cursor Agent の URL）、続いて背景・結論・詳細を書く。
