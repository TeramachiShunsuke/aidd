# セットアップガイドへ乗せる

## いつ使うか

- 新しい参加者が何から読めばいいか分からないとき
- 「使い方」「セットアップ」と尋ねられたとき
- 考え方への共感を先に求めそうなとき

## 先に読むもの

1. [SETUP.md](../../../SETUP.md) — 人向けの始め方（二層）
2. [PB-019](../../../playbook/019-onboard-with-setup-guide.md) — 手順の正本
3. [ADR-021](../../../adr/021-two-layer-setup-guide.md) — 二層と全共感を成功条件にしないこと

## 手順の要点

1. 最低限（無駄なく使う）か、理解したら（改善できる）かを 1 つ選ぶ
2. SETUP.md の該当節だけを渡す。AGENTS.md から始めない
3. 今の作業があれば INDEX から playbook を 1 つ開いて 1 周させる
4. 案件固有の始め方は kernel の SETUP に足さない

## 禁止事項

- 全文書の通読や考え方への共感を、使い始めの条件にする
- SETUP に CONVENTIONS の規範値を書き写す
- 手順の詳細をこのファイルに書き写す（正本は PB-019）
